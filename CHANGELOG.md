# Changelog

## 1.0.0 - 2026-08-20

- Added the full OpenITI catalog with title, author, and URI search.
- Added per-version downloads, local caching, offline reading, and a local library.
- Added RTL reading, table of contents navigation, in-book search, bookmarks, and progress.
- Added compact Material 3 UI styling for catalog, library, details, and reader screens.
- Added a non-destructive SQLite migration for existing app data.
- Added optional release signing properties, R8/resource shrinking, CI, and Android instrumentation coverage.
