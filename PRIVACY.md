# Maktaba Privacy Notice

Last updated: 2026-08-20

## Summary

Maktaba does not require an account and does not include advertising, analytics,
or third-party tracking. The application does not intentionally collect personal
information.

## Network Requests

The application contacts the OpenITI release hosted on GitHub to import the
catalog and download requested book texts. GitHub may receive normal network
information such as an IP address as part of serving those requests. Maktaba
does not send reading history, bookmarks, or progress to a Maktaba server.

## Local Data

The application stores catalog metadata, downloaded texts, reader indexes,
bookmarks, and reading progress in its private application storage. This data is
not synchronized to an online account. Clearing application data or uninstalling
the application removes the local data according to Android's storage behavior.

## Export

The hidden export gesture uses Android's system document picker. A file is only
written to a location selected by the user. Maktaba does not request broad shared
storage access.

## Third Parties

OpenITI content and GitHub services are third-party resources governed by their
own terms and policies. See [NOTICE.md](NOTICE.md) for attribution details.

## Contact

For privacy questions or requests, open an issue in the
[Maktaba repository](https://github.com/opennur/maktaba/issues).
